# Frontend Application (React & Vite)

This directory contains the single-page React frontend built with **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## Key Features

* **URL State Synchronization:** Search parameters, filters, sorting, and slide-overs map directly to browser query parameters for instant shareability and state restoration on page reload.
* **Serpentine Activity Timeline:** Custom visual track displaying lead progressions with interactive nodes, hover previews, and conversational threaded notes popovers.
* **Server-Dependent Pagination:** Fully integrated with backend pagination, supporting custom rows per page (`25`, `50`, `100`).
* **Role-Based Views:** Dynamic UI rendering based on whether the logged-in user is an `Admin` or `Member`.

---

## Quick Setup & Running

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Vite dev server:
   ```bash
   npm run dev
   ```
